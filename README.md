# One Emoji, One Smile

This entry is a lightweight Node 22 program that writes a single warm emoji to entry.txt, operating in a fully deterministic manner with zero network calls and no external dependencies. Because simplicity and genuine human connection trump complexity, delivering an instant spark of joy requires nothing more than one heartfelt glyph.

## How to run

Run the program using Node.js:

\`\`\`bash
node main.ts
\`\`\`

You can optionally configure the output directory by setting the `MAKEFUN_OUTPUT_DIR` environment variable:

\`\`\`bash
MAKEFUN_OUTPUT_DIR=./custom-output node main.ts
\`\`\`
